# terminalEmulator
A simple terminal emulator written in C++, capable of a handful of commands.

### Compilation Commands:
* **Compile the project:**
  ```bash
  make
  ```
* **Clean build files (object files and executable):**
  ```bash
  make clean
  ```
* **Run the emulator directly after compilation:**
  ```bash
  ./terminal.exe
  ```
